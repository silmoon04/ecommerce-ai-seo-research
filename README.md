# The AI commerce question

An interactive research report on whether ecommerce AI SEO could become a viable paid product.

The report includes eight original conceptual illustrations, three editable calculators, sourced market comparisons, a competitor table, a proposed pilot and a searchable library of fifteen research notes plus a shorter reading edition.

Research snapshot: 28 September 2026. Published evidence is distinguished from hypothetical business scenarios. The report is desk research, not a merchant survey or live product trial.

The 29 September follow-up, `competitive-deep-dive.html`, adds 30 product profiles, 13 research notes, a support-capacity calculator, documented competing features, and five opportunities with explicit tests and stopping conditions. It corrects the assumption that private vendors are unprofitable and narrows the original catalogue-repair hypothesis against stronger existing competitors. Structured data and the 15 independently checked economic scenarios are in `deep-dive/`.

The third report, `conversion-lab.html`, examines the shared controlled-replay proposal and its competition. Eighteen separate GPT-6 Astra Max product studies and eight divergent idea studies produced 260 candidates, screened into 50 distinct product hypotheses. The report includes a 22-product harness capability comparison, the full product studies and candidate ideas, an interactive mechanism map, a value/eligibility calculator and a sample-size calculator. The selected ideas specify the intervention, existing alternatives, proposed advantage, actual-purchase experiment, dependencies, falsifier and conditional economics. No live merchant experiment or willingness-to-pay study has been run. The scenarios are assumptions, not predicted conversion gains.

The complete selected set is downloadable as Markdown, JSON and CSV under `conversion-research/`. That folder also contains all 260 candidates, every selection decision, source-linked notes and the economics assumptions. The newer report updates earlier coverage of native simulation, feed experiments and purchase testing; links to it appear in both preceding reports.

## Run locally

Open `index.html` in a browser, or serve this directory with a local HTTP server. All presentation assets and dependencies are bundled. No API keys or build step are required.

## Hosting

GitHub Pages serves the repository root. The `.nojekyll` file preserves the plain static files. The website uses relative links so that its assets and research library work under a repository URL.

Manrope and Marked licence notices are included in `assets` and `vendor`.
