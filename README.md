# The AI commerce question

An interactive research report on whether ecommerce AI SEO could become a viable paid product.

The report includes eight original conceptual illustrations, three editable calculators, sourced market comparisons, a competitor table, a proposed pilot and a searchable library of fifteen research notes plus a shorter reading edition.

Research snapshot: 28 September 2026. Published evidence is distinguished from hypothetical business scenarios. The report is desk research, not a merchant survey or live product trial.

## Run locally

Open `index.html` in a browser, or serve this directory with a local HTTP server. All presentation assets and dependencies are bundled. No API keys or build step are required.

## Hosting

GitHub Pages serves the repository root. The `.nojekyll` file preserves the plain static files. The website uses relative links so that its assets and research library work under a repository URL.

Manrope and Marked licence notices are included in `assets` and `vendor`.
