Before you decide.

Do I upload my activity to a server?

The file input reads GPX on this device. The tool has no network upload or API. Original activity metadata is ignored. If you later share the exported art, the retained route geometry is visible.

Is the distance my watch's distance?

No. Computed distance uses a spherical haversine sum of the retained point sequence and excludes gaps and elevation. Alternatively enter a distance you have checked and explicitly confirm it, or leave distance off.

Can I buy the physical print now?

There is no checkout in this prototype. The £24.99 delivered UK price is a hypothesis pending Papello's exact A4 print, paper, tax, packaging and postage quote plus a physical sample.

Does the drawing use map imagery?

It draws GPX route geometry only. It has no basemap, place labels, tile downloads or map imagery licences.

Can I buy this here?

This is a storefront prototype with a local cart and checkout simulation. It does not accept payments, collect your address or place an order. A native Shopify product and checkout still need to be connected.

What does the proposed price mean?

It is a price to test with potential customers. Demand, support costs and any physical production costs have not yet been validated.

Local preview measurements are off. If you allow them, clicks are kept in memory for this browser session. There is no analytics server. The essential cart saves product IDs and quantities on this device.
